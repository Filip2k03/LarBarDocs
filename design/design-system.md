# 🎨 Red & Gold Design System (100 - 900)

The LarBar platform UI design language uses an **Imperial Crimson Red** and **Royal Gold** color system paired with **Noir Onyx** dark mode surfaces.

---

## 🔴 Imperial Crimson Red Palette (`red-100` to `red-900`)

| Token | Hex Code | RGB / HSL | Semantic Usage & Role |
|---|---|---|---|
| `red-100` | `#FFE8E8` | `rgb(255, 232, 232)` | Lightest tint, error badge surface, soft warning background |
| `red-200` | `#FFC2C2` | `rgb(255, 194, 194)` | Subtle red borders, alert chip outlines |
| `red-300` | `#FF8F8F` | `rgb(255, 143, 143)` | Secondary warning text, outline buttons |
| `red-400` | `#F85A5A` | `rgb(248, 90, 90)` | Hover state for secondary red actions |
| `red-500` | **`#E5252A`** | `rgb(229, 37, 42)` | **PRIMARY BRAND RED** - SOS Trigger, Critical CTA, Active Accent |
| `red-600` | `#C41419` | `rgb(196, 20, 25)` | Primary button hover state, critical alert header |
| `red-700` | `#9E0D11` | `rgb(158, 13, 17)` | Active / pressed button state, high-contrast dark text |
| `red-800` | `#74070A` | `rgb(116, 7, 10)` | Deep crimson card container, dark theme card background |
| `red-900` | `#480204` | `rgb(72, 2, 4)` | Darkest crimson surface, deep shadow blend |

## 🖤 Neutral Dark Surfaces (`neutral-100` to `neutral-900`)

- `neutral-900`: `#0E0F14` (Main Application Dark Background)
- `neutral-800`: `#181922` (Card / Bottom Sheet Surface)
- `neutral-700`: `#282836` (Border / Divider / Inactive Tab)
- `neutral-100`: `#FFFFFF` (Primary Text / High-Contrast Elements)
